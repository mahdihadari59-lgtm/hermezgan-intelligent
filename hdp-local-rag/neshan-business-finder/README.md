# یاب — Neshan Business Finder

اپلیکیشن جست‌وجوی کسب‌وکارهای اطراف روی نقشه نشان، با نمایش مسیر، ترافیک زنده و فیلتر دسته‌بندی.

## ویژگی‌ها

- 🗺️ نقشه تعاملی با تایل‌های نشان (Leaflet + react-leaflet)
- 🔍 جست‌وجو و فیلتر کسب‌وکارها بر اساس دسته‌بندی
- 📍 تشخیص موقعیت مکانی کاربر (Geolocation) و محاسبه فاصله زنده
- 🧭 محاسبه و نمایش مسیر (فاصله/زمان) با انتخاب نوع وسیله (خودرو/موتور)
- 🚦 لایه ترافیک زنده نشان
- 🔔 نوتیفیکیشن‌های شناور (Toast) برای خطاها و رویدادها

## پیش‌نیاز: کلید API نشان

1. در [پنل توسعه‌دهندگان نشان](https://developer.neshan.org) ثبت‌نام کنید.
2. یک **وب‌سرویس (Web Service)** برای Search/Direction/Reverse بسازید → `VITE_NESHAN_API_KEY`
3. یک **Map Key** برای تایل نقشه و ترافیک بسازید → `VITE_NESHAN_MAP_KEY`
4. مقادیر را در فایل `.env` جایگزین کنید.

> ⚠️ بدون کلید API، پروژه همچنان اجرا می‌شود اما از داده نمونه (`src/data/businesses.ts`)
> و تایل جایگزین OpenStreetMap استفاده می‌کند تا توسعه بدون وقفه ممکن باشد.

## نصب و اجرا

```bash
npm install
npm run dev
```

سپس به آدرس `http://localhost:5173` بروید.

## ساخت نسخه Production

```bash
npm run build
npm run preview
```

## ساختار پروژه

```
src/
├── components/   کامپوننت‌های UI (نقشه، سایدبار، کارت، پنل مسیر، ترافیک، توست)
├── hooks/        منطق اتصال به API نشان، موقعیت‌یابی، محاسبه مسیر
├── data/         داده نمونه کسب‌وکارها (fallback)
├── types/        تایپ‌های TypeScript مشترک
└── App.tsx       اتصال همه اجزا به یکدیگر
```

## نکات فنی

- مسیر با الگوریتم استاندارد Polyline دی‌کد می‌شود (فرمت خروجی API مسیریابی نشان).
- در نبود کلید API، فاصله با فرمول هاورساین و مسیر با خط مستقیم تخمین زده می‌شود.
- طراحی به‌صورت راست‌به‌چپ (RTL) و با فونت وزیرمتن پیاده‌سازی شده است.
